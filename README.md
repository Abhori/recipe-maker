# 🍲 Recipe Maker

A modern React-based web application that allows users to explore, search, and manage recipes with a clean and user-friendly interface.

---

## 🚀 Features

- 🔍 Search for recipes
- 📖 View detailed recipe information
- ➕ Add your own recipes (if implemented)
- 💻 Responsive and clean UI
- ⚡ Fast performance using Vite + React

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Styling:** CSS / Tailwind (update if you used one)
- **Package Manager:** npm
